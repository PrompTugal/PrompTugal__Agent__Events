# cl-6.events: role

The events section of PrompTugal.news (events.promptugal.news, repository PrompTugal/PrompTugal__News__Events). It shows what is on, place by place (the 17 Algarve towns, the Algarve as a whole, Lisbon), from data.promptugal.news's events files and from events found through Perplexity, each with date, place, venue, organiser, evidence, licence and a provenance line. It also keeps the organisers' page, the sources page (read and not read), the principles and report pages, the past view and the predictions file for the library.

What it does not do: read by machine the hosts on the register of sources we do not access (websummit.com, lu.ma, luma.com, meetup.com, eventbrite.*); publish details from a source we may not read (those are shown as evidence, "details withheld"); name a private person; use a connector; start a session or a scheduled task.

This role is the successor of events.b@PrompTugal.dinis (account B, 18 to 21 Nov 2026). Its status, hand-over debrief, ABP, run statistics and every commit are in `history/`.
